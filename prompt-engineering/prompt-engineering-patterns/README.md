# 使用 Spring AI 进行提示词工程

![Spring AI Prompt Engineering](prompt-engineering-spring-ai.png)

## 概述

本仓库包含使用 [Spring AI](https://docs.spring.io/spring-ai/reference/index.html) 实现提示词工程技术的实际示例。这些示例配套博客文章：[Spring AI Prompt Engineering Patterns](https://spring.io/blog/2025/04/14/spring-ai-prompt-engineering-patterns)。

这些示例和模式基于内容全面的 [Prompt Engineering Guide](https://www.kaggle.com/whitepaper-prompt-engineering)，该指南涵盖有效提示词工程的理论、原则与模式。

这里展示如何使用 Spring AI 的流式 [ChatClient API](https://docs.spring.io/spring-ai/reference/api/chatclient.html) 将这些概念转化为可运行的 Java 代码。


#### 结构

这些示例遵循原始 Google Prompt Engineering 指南中列出的相同结构与模式，便于在理论与实现之间相互参照。
